# 뉴스 자동화 스킬

관심 주제의 최신 뉴스를 검색하고 중복과 출처 신뢰도를 점검해, 링크가 포함된 데일리·주간 브리핑으로 정리하는 스킬입니다.

## 주요 기능

- 기업·산업·기술·정책 등 관심 주제 모니터링
- 원문과 공식 발표를 우선한 출처 검증
- 같은 사건을 다룬 기사 중복 제거
- 게시일과 실제 사건일 구분
- 정기 브리핑 자동화 요청 지원
- 검색 실패와 실제 뉴스 부재를 구분

## 사용 방법

1. 이 저장소를 내려받거나 ZIP 파일로 다운로드합니다.
2. `news-automation` 폴더를 사용하는 AI 도구의 스킬 폴더에 추가합니다.
3. 아래와 같이 요청합니다.

```text
$news-automation을 사용해 최근 24시간의 한국어 AI 뉴스 중 중요한 소식 5건을 브리핑해 줘.
```

자동 실행을 원할 때는 주제, 주기, 시각과 시간대, 결과 형식, 전달 위치를 함께 지정하세요.

```text
매주 월요일 오전 9시(KST)에 지난 7일간의 생성형 AI 정책 뉴스를 찾아 이 대화에 브리핑해 줘.
```

## 구성

- `SKILL.md`: 실행 조건과 핵심 작업 지침
- `references/briefing-template.md`: 기본 뉴스 브리핑 형식
- `agents/openai.yaml`: 스킬 표시 이름과 기본 실행 예시

## 주의사항

뉴스 브리핑은 정보 제공을 위한 것이며 투자·법률·의료 판단을 대신하지 않습니다. 스킬을 공유하기 전에 회사 내부정보, 개인정보, 비밀번호, API 키가 포함되어 있지 않은지 확인하세요.
