# 뉴스 브리핑 형식

이 형식은 사용자가 별도 출력 형식을 지정하지 않았을 때 사용한다.

```markdown
# [주제] 뉴스 브리핑

기준: 2026년 8월 27일 09:00 KST · 검색 범위: 최근 24시간

## 한눈에 보기

- 오늘의 가장 중요한 흐름을 2~3문장으로 요약

## 주요 뉴스

### 1. 간결한 제목

무슨 일이 있었는지 1~2문장으로 설명한다.

왜 중요한지: 사용자 관점의 영향이나 다음 관찰 지점을 1문장으로 설명한다.

날짜: 사건일 또는 게시일  
출처: [원문 또는 공식 발표](https://example.com)

## 지켜볼 것

- 아직 확정되지 않았지만 후속 확인 가치가 있는 사항

## 수집 메모

- 제외 기준, 접근 제한, 소식이 적었던 경우 등 결과 해석에 필요한 제한만 기록
```

항목마다 모든 섹션을 기계적으로 채울 필요는 없다. `지켜볼 것`과 `수집 메모`는 실제로 도움이 될 때만 포함한다.
